## 1. P0-1 黑名单二分查找上界越界

**文件**：3018-3030-TP/xa_cpu20_operation.c，函数 `check_metro_Black_Lock`
**根源对应**：主报告 6.6.1（ghost 槽位误命中机制 A）

### 1.1 现状（:6474-6475）

```c
    //use the binary method to find the BLACK No
    lngCSCLowIndex = 0;
    lngCSCHighIndex = tpBlacklist1104.CardBlack_val.blacknum;
```

### 1.2 修改后

```c
    //use the binary method to find the BLACK No
    lngCSCLowIndex = 0;
    //20260826 P0-1：上界必须为 blacknum-1（有效下标范围 [0, blacknum-1]）。
    //原值 blacknum 在"卡号大于全部名单条目"时 mid 越界读出名单末尾之外的 ghost 槽位，
    //与 P0-2 的缓冲不复位叠加，正常卡被误命中并静默锁卡（0x03/0x08 的根源）。
    lngCSCHighIndex = tpBlacklist1104.CardBlack_val.blacknum - 1;
```

### 1.3 附带清理（:6510）

删除循环体内这句死代码（mid 在 :6495 已计算，此处重复计算且结果无用，易误导阅读）：

```c
        lngCSCMidIndex = (lngCSCLowIndex + lngCSCHighIndex) / 2;
```

### 1.4 说明与风险

- blacknum=0 时上界为 -1，`while(lngCSCLowIndex <= lngCSCHighIndex)` 不进入，与 :6477 的 `!= 0` 守卫双重保护，无风险。
- blacknum=1 时上界 0，mid=0，命中判断正确。
- 二分查找要求名单按 CardID 严格升序——升序校验由 P0-2 一并补上（数据侧兜底）。

## 2. P0-2 1104 名单下载缓冲清零与完整性校验

**文件**：3018-3030-TP/bin_file_manage.c（1104 参数文件下载函数）
**根源对应**：主报告 6.6.1（ghost 槽位误命中机制 A：free+malloc+fread 不复位）

### 2.1 现状（:724-730，卡黑名单）

```c

		if(tpBlacklist1104.CardBlack_val.CardBlacklist_val == NULL)
		{
			fclose(intFile);
			return 1;
		}
		fread(tpBlacklist1104.CardBlack_val.CardBlacklist_val, sizeof(CardBlacklist_t), tpBlacklist1104.CardBlack_val.blacknum, intFile);
```

### 2.2 修改后（:724-730）

```c
		tpBlacklist1104.CardBlack_val.CardBlacklist_val = (CardBlacklist_t *)malloc(sizeof(CardBlacklist_t) * tpBlacklist1104.CardBlack_val.blacknum);
		if(tpBlacklist1104.CardBlack_val.CardBlacklist_val == NULL)
		{
			fclose(intFile);
			return 1;
		}
		//20260826 P0-2：malloc 后必须清零。旧名单条数多于新名单时，未覆盖的槽位
		//残留旧数据（ghost 槽位），配合 P0-1 的越界上界造成正常卡误命中锁卡。
		memset(tpBlacklist1104.CardBlack_val.CardBlacklist_val, 0x00, sizeof(CardBlacklist_t) * tpBlacklist1104.CardBlack_val.blacknum);
		if(fread(tpBlacklist1104.CardBlack_val.CardBlacklist_val, sizeof(CardBlacklist_t), tpBlacklist1104.CardBlack_val.blacknum, intFile) != (size_t)tpBlacklist1104.CardBlack_val.blacknum)
		{
			//20260826 P0-2：名单读取不完整时整表作废——宁可漏锁，不可误锁。
			PRINTK("1104 cardblack list read incomplete, blacklist disabled\n");
			tpBlacklist1104.CardBlack_val.blacknum = 0;
			free(tpBlacklist1104.CardBlack_val.CardBlacklist_val);
			tpBlacklist1104.CardBlack_val.CardBlacklist_val = NULL;
		}
		else
		{
			//20260826 P0-2：二分查找前提——校验 CardID 严格升序；乱序名单作废并告警。
			for(i = 1; i < tpBlacklist1104.CardBlack_val.blacknum; i++)
			{
				if(tpBlacklist1104.CardBlack_val.CardBlacklist_val[i].CardID <= tpBlacklist1104.CardBlack_val.CardBlacklist_val[i - 1].CardID)
				{
					PRINTK("1104 cardblack list not ascending at index %d, blacklist disabled\n", i);
					tpBlacklist1104.CardBlack_val.blacknum = 0;
					free(tpBlacklist1104.CardBlack_val.CardBlacklist_val);
					tpBlacklist1104.CardBlack_val.CardBlacklist_val = NULL;
					break;
				}
			}
		}
```

### 2.3 同样改法套用另外两处

| 位置 | 现状 | 动作 |
|---|---|---|
| :751-757 区段黑名单 | malloc 后直接 fread | malloc 后加 memset + fread 完整性校验（不足则 sectionnum=0 并释放） |
| :777-783 产品黑名单 | malloc 后直接 fread | 同上（不足则 productnum=0 并释放） |

区段/产品名单是顺序遍历（非二分），无需升序校验；清零 + 完整性校验即可。

### 2.4 说明与风险

- `PRINTK` 宏在该文件已使用（DEBUG_1104_PRINT 块内及他处），可用。
- 行为变化：名单文件损坏/截断时整表作废（返回后 TP 视为无黑名单），比误锁安全；后台可从日志发现名单异常。
- 后台数据侧仍需保证 1104 名单本身排序、去重、区间与发卡号段不冲突（见第 12 节）。

## 13. 回归测试场景

### 13.1 P0-1/P0-2 黑名单（单元级，构造名单文件验证）

1. blacknum=0 空表：任意卡号 → 不命中、无越界读；
2. 单条名单：卡号 < / = / > 条目（旧代码">"越界读 [1] 槽，新代码不命中）；
3. 多条名单：卡号大于全部条目（旧代码越界读 [N] 槽，新代码不命中）；
4. 名单收缩复现：先下载 10 条再下载 3 条，用旧第 4 槽卡号验证（旧代码命中、新代码不命中）；
5. 名单升序校验：构造乱序名单 → 名单作废告警、不参与查找；
6. 名单截断：构造 fread 不足的 1104 文件 → 名单作废、不参与查找。

### 13.2 P0-3 区段名单

1. 卡号 = Start / = End / 区间外 → 命中/不命中正确；
2. 非法区间（Start > End、Start=0）→ 跳过不命中；
3. 命中 → 日志含区间值与卡号。

### 13.3 P0-4 静默锁卡

1. 构造误命中名单完整跑进站：返回 0x01、**不写文件 15/17**（写前读卡比对验证）、日志有 BLACK-HIT-NOWRITE；
2. 读卡验证卡片 cardStatus/productStatus 保持 01/01；
3. 真黑名单卡进站：仍 0x01 拦截（上位机行为不变）。

### 13.4 P0-5 defer TIMES

1. 过期 TIMES 卡 defer：返回 CE_NON_FEETYPE、读卡验证文件 1C 未被改写；
2. 未过期 TIMES 卡 defer：仍 CE_NONACTIVED（行为不变）。

### 13.5 P0-6 0715 块

1. 正常 1D 卡交易/查询/延期全绿（读路径回归）；
2. 构造"已激活但起始日期在未来"卡：交易不写卡、日志有 DAMAGED-1D-SUSPECT。

### 13.6 P1-1/P1-2 恢复块

1. 模拟交易中 active_em 改期 → 交易结束恢复块应把起始日期回滚为 :2016 基准（读卡验证）；
2. 无改期发生时恢复块不应触发写卡（读前读后文件 1D 比对一致）。

### 13.7 全量回归

- 员工卡/公务票：进站、出站、更新、查询、延期、锁卡、激活各命令全绿；
- 黑名单命中/未命中路径日志齐全；
- 编译零警告（P0-6 删除块后的未用变量清理见 6.3）。
